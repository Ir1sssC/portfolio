# RoomieBoard — 留学生合租协作看板

面向计划合租的留学生的房源讨论与决策网页交互原型。帮助室友集中查看房源、讨论优缺点、整理看房问题，并标记下一步跟进状态。

## 体验

- GitHub Pages 首页：`https://ir1sssc.github.io/portfolio/` （需要在仓库 Settings → Pages 中启用 `main` / `/(root)` 才能公开访问）
- `index.html`：GitHub Pages 站点入口
- `test2.html`：原始交互页面的副本，便于后续 Codex 修改

## 原型功能

- 房源图片轮播及缩略图
- 租金、房型、设施、入住时间与通勤信息
- 八维评分展示及房源优缺点
- 评论输入、看房问题清单（新增、编辑、删除）
- 收藏、待确认、继续看等前端交互

> **Demo notice**：这是一份使用示例房源信息和示意评分的静态前端原型，不是实时房源核验服务。评论和操作目前没有多人共享数据库或跨设备同步，刷新页面后会丢失未保存的操作。部分图片、地图及图表来自外部服务，需要联网加载。
